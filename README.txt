JACOPS-presentatie — deploy-instructies

Inhoud: index.html + 7 MP4-films (alles in deze map, geen submappen).

Deployen:
1. Upload de VOLLEDIGE map naar de webserver of het portal (bestandsnamen ongewijzigd laten).
2. index.html is het startpunt; de video's worden relatief geladen uit dezelfde map.
3. Werkt op elke statische host (GitHub Pages, Netlify, S3, intranet-webserver).
4. Geen server-side code of database nodig; HTTPS aanbevolen.

Let op: de kijker moet elke film volledig uitkijken voor de knop Verder ontgrendelt.
